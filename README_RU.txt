ОДИН ТЕКСТ — ПЯТЬ ГОЛОСОВ · версия 2.0

ЧТО ВНУТРИ
- Адаптивный сайт для учителя и ученика
- Конструктор собственных текстов и вопросов пяти ролей
- Сохранение черновиков в браузере, экспорт резервной копии
- Серверная функция /api для создания урока, выдачи кода, приёма ответов, просмотра ответов и выгрузки CSV
- Отдельные ответы учеников сохраняются в Netlify Blobs

ВАЖНО: Для работы телефонов с интерактивной доской нужен деплой с Netlify Functions.
Простая загрузка ZIP через Netlify Drop может опубликовать только статическую часть и НЕ активировать серверные функции.
Поэтому для полноценного запуска:
1. Распакуйте ZIP в отдельную папку.
2. Загрузите содержимое папки в репозиторий GitHub (корень репозитория: index.html, app.js, package.json, netlify.toml, netlify/functions/api.mjs).
3. В Netlify откройте свой сайт -> Site configuration / Build & deploy -> Link repository (или создайте новый сайт через Import from Git).
4. Подключите репозиторий. Build command: npm run build. Publish directory: . (точка). Functions directory: netlify/functions.
5. Выполните Deploy. Netlify установит @netlify/blobs и соберёт функцию.
6. Проверьте https://ВАШ-САЙТ/api?ping=1 — ожидается {"ok":true,"mode":"cloud"}.
7. Откройте сайт, создайте урок, нажмите Запустить. Сохраните секретный ключ учителя.
8. На телефоне откройте ссылку с кодом, отправьте ответ. На доске нажмите Обновить.

НЕ ПУБЛИКУЙТЕ СЕКРЕТНЫЙ КЛЮЧ УЧИТЕЛЯ.
УЧЕНИКИ: вводят учебный псевдоним и код. Не используйте ФИО без разрешения и соблюдения школьных правил персональных данных.

ОГРАНИЧЕНИЯ:
- Кабинет учителя в этой версии защищён секретным ключом конкретного занятия, но нет полноценной регистрации педагогов.
- Черновики хранятся в браузере: регулярно экспортируйте резервную копию.
- Урок нельзя редактировать после запуска; для изменений создайте новую сессию.
- QR-код автоматически не рисуется: ученики могут открыть ссылку или ввести код.
- Нет автоматической оценки интерпретации и нет генерации вопросов ИИ.
- Доступ к тексту имеют все, кто знает код урока. Не размещайте конфиденциальные тексты.
- Для больших классов и долгосрочной эксплуатации нужны дополнительная защита от спама, ограничение частоты запросов и полноценные учётные записи.
- Эта версия рассчитана на пилотное применение, а не на общешкольный сервис с персональными данными.

Если /api?ping=1 не работает, сайт опубликован без серверной функции. Для работы между устройствами необходимо подключить Git-репозиторий.
