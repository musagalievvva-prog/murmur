ОДИН ТЕКСТ — ПЯТЬ ГОЛОСОВ · 2.1

РАБОТАЕТ
Конструктор урока, пять постоянных ролей, редактирование вопросов.
Режимы: в классе (пять групп), самостоятельно, домашнее расследование.
Речевые опоры отличаются для 5, 6 и 7 классов.
Запуск урока, код, ссылка и QR, который строится локально в браузере.
Ответы учеников и оценки учителя хранятся в Netlify Blobs.
Учитель оценивает четыре критерия по 0–2 балла; максимум 8.
Оценки выгружаются вместе с ответами в CSV.
Общая открытая библиотека: публикация с согласием автора, поиск,
фильтр по классу, сохранение редактируемой копии, снятие своей публикации.
Черновики и ключи учителя остаются в браузере. Делайте резервные копии.
При смене устройства восстановите резервную копию.

ВОПРОСЫ С ИИ
В конструкторе есть кнопки: автоматическая генерация, копирование промпта
с текстом и импорт JSON из ChatGPT. Без подключения ИИ-сервиса действует
промпт и импорт: автоматическая кнопка честно показывает, что сервис
не подключён. Это не имитация генерации шаблонными вопросами.
Для автоматической генерации владелец сайта должен добавить в Netlify
секретную переменную OPENAI_API_KEY (область Functions).
Не добавляйте ключ в GitHub и клиентский JavaScript.
Необязательная переменная OPENAI_MODEL; по умолчанию gpt-4.1-mini.
Запросы оплачиваются владельцем ключа; предусмотрено ограничение 10 в день
на сетевой адрес. Для публичного массового сервиса нужна полноценная
аутентификация и более строгие квоты. Вопросы проверяет учитель.
Текст для генерации отправляется в OpenAI; не включайте личные данные.

ПУБЛИКАЦИЯ
Сайт связан с musagalievvva-prog/murmur, ветка main.
Build command: npm run build; publish: .; functions: netlify/functions.
Для работы сервера нужен Git-деплой, а не простая статическая загрузка.

ДАННЫЕ
Секрет конкретного занятия защищает ответы и оценки. Отдельной регистрации
учителей нет. Код занятия даёт ученикам доступ к тексту и отправке ответа.
Снятая публикация исчезает из библиотеки; уже сохранённые копии остаются.
Опубликованные тексты видны всем. Публикуйте только свои или разрешённые
материалы без личных данных. Библиотека пилотная, без премодерации.
